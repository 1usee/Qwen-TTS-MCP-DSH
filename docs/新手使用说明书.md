## 1. 这个项目能干什么

它是一个「插件」，把 **Qwen 语音功能**接到 **DeepseekHarness** 里，让你用说话的方式就能用：

| 你想做的事 | 你只要说 | 背后发生什么 |
|---|---|---|
| 知道有哪些声音可选 | 「列出可用的语音模型」 | 查询模型清单 |
| 把文字变成语音 | 「请把"你好世界"转成语音」 | 生成一个音频文件 |
| 复制某个人的音色 | 上传一段录音 + 「克隆这个音色」 | 生成专属音色编号 |
| 看看还剩多少钱 | 「查询账户余额」 | 查询余额 |

几个你需要先知道的事实：

- **三件事里有两件要花钱**（转语音、克隆音色）。查清单和查余额是免费的。
- **钱花在阿里云（Qwen 的东家）账户上**，不是花在这个软件上。本项目完全免费。
- 生成的音频是**文件**，存在你电脑上，可以直接播放。
- 克隆音色时，**参考录音需要 5～60 秒**，太短太长都不行。

## 2. 开始前的准备（约 15 分钟）

请按顺序完成，缺一不可。

### ✅ 检查清单

- [ ] Windows 电脑
- [ ] 能上网
- [ ] DeepseekHarness 已安装，能正常打开
- [ ] Python 3.10 或更高版本（下面教你怎么查）
- [ ] 一个阿里云账号（下面教你怎么弄）

### 2.1 安装本项目

1. 按键盘 `Win 键`，输入 `PowerShell`，回车。会弹出一个蓝色或黑色的窗口。
2. 先确认有 Python（3.10 以上）：

```powershell
python --version
```

**应该看到**类似 `Python 3.11.16`。如果提示「不是内部或外部命令」，去
<https://www.python.org/downloads/> 下载安装，**安装第一个界面记得勾选
`Add python.exe to PATH`**，装完重开 PowerShell 再试。

3. 安装本项目（会得到一个叫 `qwen-voice-mcp` 的命令）：

```powershell
cd F:\MCP_Server\Qwen-TTS-MCP-DSH
pipx install .
```

如果提示没有 `pipx`，用这两条代替：

```powershell
python -m pip install --user pipx
python -m pipx install .
```

4. 确认装好了：

```powershell
qwen-voice-mcp version
```

**应该看到** `1.0.0`。看到就可以进入第 3 章。

## 3. 第一步：拿到 API 密钥

API 密钥长这样：`sk-` 开头，后面一长串字母数字，例如
`sk-1234567890abcdefghijklmnopqrst`。

它就像**你账户的钥匙 + 钱包**：谁能用它，谁就能花你的钱。所以千万别发到群里、别写进记事本、别提交到代码仓库。

### 怎么获取

1. 打开阿里云百炼（DashScope）控制台：<https://bailian.console.aliyun.com/>
2. 用阿里云账号登录（没有就注册一个，需要实名认证）
3. 在控制台里找到 **API-KEY 管理**（通常在右上角头像菜单里，或左侧「API-KEY」入口）
4. 点 **创建我的 API-KEY**
5. 复制那串 `sk-` 开头的字符

> ℹ️ 各家控制台界面会改版，所以这里没写死按钮位置。认准两个关键词：
> **「百炼」/「模型服务」** 和 **「API-KEY 管理」**。
> 如果找不到，在本项目里直接问 DeepseekHarness：「阿里云百炼的 API Key 在哪里创建？」

### 充值（不充值就没法转语音）

新账号通常有免费额度，用完后需要充值：

1. 在同一个控制台找到 **费用 / 充值** 入口
2. 充一点即可（比如 10 元），够用很久

> 本项目默认设了一条「安全线」：**账户余额低于 ¥1.00 时拒绝执行**，
> 免得你在不知情的情况下把钱花光。这条线可以调，见 8.7。

## 4. 第二步：把密钥填进去

两种方式，**任选一种**。推荐方式 A。

### 方式 A：图形界面（推荐给新手）

在 PowerShell 里粘贴：

```powershell
qwen-voice-mcp gui
```

**会弹出一个窗口**，长这样：

```
┌─ Qwen Voice MCP — 配置中心 ──────────────────────┐
│ ┌─ API 配置 ──────────────────────────────────┐ │
│ │ API Key: [••••••••••••••••]      [验证] [显示]│ │
│ │          ● 未验证                            │ │
│ └──────────────────────────────────────────────┘ │
│ ┌─ 服务配置 ──────────────────────────────────┐ │
│ │ 传输方式:  (•) stdio   ( ) streamable-http   │ │
│ │ 监听端口:  [8765]                            │ │
│ │ 默认音色:  [longanyang ▼]                    │ │
│ │ 余额阈值:  [1.00]   □ 严格模式               │ │
│ └──────────────────────────────────────────────┘ │
│ [保存配置] [测试连接] [刷新模型] [清除密钥]      │
└──────────────────────────────────────────────────┘
```

操作步骤：

1. 把 `sk-` 开头的密钥粘贴到 **API Key** 框里（默认显示成圆点，这是正常的防偷看）
2. 点 **验证**
   - **成功**会显示：`● 已验证 — 账户余额 ¥12.50`
   - **失败**会显示原因（见 8.2）
3. 点 **保存配置**
   - 会显示 `● 已保存 — C:\Users\...\config.json`

到这里就配置好了，**跳到第 5 章**。

> 💡 如果点「保存配置」时弹出「密钥未通过验证」，它问你「仍要保存吗」。
> 只是网络不通的话可以选「是」；如果密钥是复制错的，选「否」并重新粘贴。

### 方式 B：命令行（一条命令搞定）

```powershell
qwen-voice-mcp setup
```

它会提示你粘贴密钥，**输入时不显示字符**（防止被人看到，这是正常的），
粘贴后回车即可。它会自动联网验证一次，然后把密钥加密存好：

```
已保存密钥 sk-123…cdef
  密钥库: C:\Users\你\AppData\Roaming\qwen-voice-mcp\vault.enc
  保护方式: 系统凭据管理器
```

> 💡 密钥**不会**留在命令历史里——因为它是交互输入的，不是写在命令行上。

然后验证一下：

```powershell
qwen-voice-mcp balance
```

**应该看到**类似：

```
账户余额 ¥12.50，状态正常。
  balance: 12.5
  currency: CNY
  ...
```

> ⚠️ 旧写法 `qwen-voice-mcp config set-key sk-xxx` 仍然可用，但密钥会出现在命令历史里，
> 不推荐。键盘输入请用 `config set-key`（不带参数，会提示隐藏输入）。

### 密钥存在哪里？

存在你自己电脑上的一个**加密文件**里：

```
C:\Users\你的用户名\AppData\Roaming\qwen-voice-mcp\vault.enc
```

它是 AES-256-GCM 加密的，**用记事本打开也是乱码**，密钥本身由 Windows
凭据管理器保管。就算有人偷走这个文件，没有你的 Windows 账户也解不开。

## 5. 第三步：让 DeepseekHarness 认识它

现在密钥有了，还要告诉 DeepseekHarness「有这么个语音插件」。

### 5.1 先自己测一下（不花钱、不联网）

这步是为了排除「是你电脑的问题还是配置的问题」。粘贴：

```powershell
qwen-voice-mcp doctor
```

**应该看到**一张表，每行都是 `OK` / `已配置` / `已注册`：

```
┌─────────────┬─────────┬──────────────────────────────┐
│ 检查项      │ 状态    │ 说明                         │
├─────────────┼─────────┼──────────────────────────────┤
│ 版本        │ OK      │ 1.0.0                        │
│ mcp 包      │ OK      │ 1.30.0（FastMCP 可用）       │
│ API Key     │ 已配置  │ 来源: 加密库 sk-123…cdef     │
│ 密钥库      │ keyring │ ...\vault.enc · 系统凭据管理器│
└─────────────┴─────────┴──────────────────────────────┘
```

**每一行都正常就说明插件本身没问题**，可以进入 5.2。
某一行为「缺失 / 不兼容 / 未配置」时，看它右边的说明，或跳到 8.1。

### 5.2 在 DeepseekHarness 里添加

1. 打开 DeepseekHarness
2. 进入 **设置 → MCP**（找不到就直接问它：「怎么添加 MCP 服务器？」）
3. 点 **添加服务器**
4. 按下面填：

| 字段 | 填什么 |
|---|---|
| 名称 | `qwen-voice`（随便起） |
| 命令 | `qwen-voice-mcp` |
| 参数 | `run --transport stdio` |
| 环境变量 | **留空** |

> 💡 环境变量留空是**故意的**：密钥在加密库里，服务启动时会自己去取。
> 把密钥填在这里等于多存一份明文，没必要。

不想手填？在 PowerShell 里跑：

```powershell
qwen-voice-mcp print-config --client dsh
```

把输出整段复制进 DSH 的配置文件（或照着填进界面）。

5. 保存并启用
6. **重启 DeepseekHarness**，让它重新读取设置

### 5.3 验证成功

新建一个对话，输入：

> 列出可用的语音模型

如果它返回了模型清单（`cosyvoice-v2` 等），**恭喜，全部配置完成！**

## 6. 日常怎么用

配置好之后，你**不需要再执行任何命令**。直接在 DeepseekHarness 对话里说人话就行。

### 6.1 查看有哪些音色（免费）

> 列出可用的语音模型

返回里每条模型都有一个 `verified` 字段：

| 值 | 意思 |
|---|---|
| `null` | 还没探测过（正常，不影响使用） |
| `true` | 已确认你的账户能用 |
| `false` | 你的账户不能用这个模型 |

想确认哪些真的能用，可以直接跟它说：

> 帮我验证一下这些语音模型哪些可用

### 6.2 把文字变成语音（要花钱）

最简单的说法：

> 请把"今天天气不错，我们出去走走吧"转成语音

也可以指定：

> 用 longanyang 这个音色，把"你好世界"转成 mp3

生成成功后会得到一个文件路径，比如：

```
C:\Users\你\AppData\Roaming\qwen-voice-mcp\output\qwen_tts_20261014_120000_ab12.mp3
```

把它复制到资源管理器地址栏，回车，双击就能播放。

### 6.3 克隆一个音色（要花钱）

**准备工作**：一段 **5～60 秒**的清晰录音。

- 格式：`wav`、`mp3`、`m4a`、`flac`、`ogg`、`aac` 都行
- 大小：不超过 20 MB
- 内容：**一个人连续说话**，别是音乐、别是多人对话、别有太多背景噪音

然后：

> 我要克隆这个音色，名字叫"我的声音"，录音在 D:\我的录音.wav

**会得到**一个 `voice_id`（音色编号），以后就能用这个音色来说话了：

> 用"我的声音"这个音色，读一下"大家好"

> ℹ️ 你起的名字（比如"我的声音"）是**存在你本地的别名**。
> 云端只接受英文小写字母数字的短编号，所以程序会自动帮你转换对应关系，
> 你只管用中文名字称呼它就行。

### 6.4 查余额（免费）

> 查询账户余额

## 7. 命令速查表

以下命令都在 PowerShell 里运行。装好之后（第 2 章），命令名就是 `qwen-voice-mcp`，
不需要再写 Python 路径。

| 我想…… | 命令 | 花钱？ |
|---|---|---|
| 首次配置（存密钥） | `qwen-voice-mcp setup` | 否 |
| 体检（装了没 / 配了没） | `qwen-voice-mcp doctor` | 否 |
| 打开图形配置界面 | `qwen-voice-mcp gui` | 否 |
| 存入密钥（另一写法） | `qwen-voice-mcp config set-key` | 否 |
| 删除密钥 | `qwen-voice-mcp config clear-key` | 否 |
| 查余额 | `qwen-voice-mcp balance` | 否 |
| 看当前全部配置 | `qwen-voice-mcp config show` | 否 |
| 改某一项配置 | `qwen-voice-mcp config set 配置项 新值` | 否 |
| 自检（不联网） | `qwen-voice-mcp selftest` | 否 |
| 探测模型可用性 | `qwen-voice-mcp verify-models` | 否 |
| 看版本 | `qwen-voice-mcp version` | 否 |
| 接入 Claude Code / Codex | `qwen-voice-mcp install --client claude,codex` | 否 |
| 打印客户端配置 | `qwen-voice-mcp print-config --client codex` | 否 |
| 启动服务（平时不用手动跑） | `qwen-voice-mcp run --transport stdio` | 否 |
| 启动 HTTP 服务 | `qwen-voice-mcp run --transport streamable-http --port 8765` | 否 |

### 可以改的配置项

用 `config set 配置项名 新值` 来改。常用几个：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `default_voice` | `longanyang` | 默认用哪个音色 |
| `balance_threshold` | `1.00` | 余额低于这个数就拒绝执行 |
| `strict_balance` | `false` | 改成 `true` = 查不到余额时也拒绝执行 |
| `port` | `8765` | HTTP 模式用的端口 |
| `default_model` | `cosyvoice-v2` | 默认用哪个模型 |
| `log_level` | `INFO` | 日志详细程度 |

例：把安全线降到 0.5 元

```powershell
qwen-voice-mcp config set balance_threshold 0.5
```

## 8. 出问题了怎么办

### 8.1 `qwen-voice-mcp doctor` 里有红字 / 显示「缺失」

先看是哪一行，再对照处理：

| 检查项 | 状态 | 怎么办 |
|---|---|---|
| 命令找不到（`不是内部或外部命令`） | — | 回第 2 章重新安装；装完**重开**一个 PowerShell 窗口 |
| `mcp 包` | 缺失 / 不兼容 | `python -m pip install "mcp>=1.2,<2"` |
| `dashscope` / `soundfile` | 缺失 | `python -m pip install dashscope soundfile` |
| `API Key` | 未配置 | `qwen-voice-mcp setup` |
| `密钥库` | 不存在 | 同上，重新 `setup` |
| `No module named 'qwen_voice_mcp'` | 已安装但当前目录不对 | `cd` 到项目目录；或直接重装 `pipx install .` |

`selftest` 仍可用，用来确认「四个工具都注册上了」：

```powershell
qwen-voice-mcp selftest
```

**应该看到**：

```
SELFTEST OK
  - list_voice_models
  - synthesize_speech
  - clone_voice
  - check_balance
```

### 8.2 提示「密钥验证失败」或 `auth_error`

可能原因，按可能性排序：

1. **密钥复制错了** —— 最常见。重新复制一次，注意**别多复制空格**，也别漏掉开头的 `sk-`
2. **密钥被禁用或删除了** —— 回控制台确认它还活着
3. **账户没实名认证** —— 回阿里云完成实名
4. **网络不通** —— 换个网络试试，或关掉代理再试

重来一次：

```powershell
qwen-voice-mcp config clear-key
qwen-voice-mcp config set-key      # 回车后会提示你粘贴，输入不显示
```

### 8.3 提示 `insufficient_balance`（余额不足）

**这是保护机制，不是故障。** 提示里会写清楚：

```
账户余额不足，当前余额 ¥0.50，预估本次合成消耗约 ¥0.11，余额阈值 ¥1.00。
请为 Qwen 账户充值后重试。
```

两个选择：

- **去充值**（推荐）：回百炼控制台充值
- **降低安全线**：`qwen-voice-mcp config set balance_threshold 0.3`

### 8.4 提示 `balance_unavailable`（查不到余额）

阿里云的余额查询接口**不是公开文档接口**，有时查不到。程序宁可说「查不到」，
也**不会假装是 0 元**（否则会误拦你每一次调用）。

默认情况下查不到余额**仍然会放行**（只给个警告）。如果你开了严格模式才会拒绝。
关掉严格模式：

```powershell
qwen-voice-mcp config set strict_balance false
```

### 8.5 提示 `invalid_input`（音频不合格）

对照检查你的录音：

| 要求 | 标准 |
|---|---|
| 时长 | **5～60 秒**（最常见的不合格原因） |
| 格式 | wav / mp3 / m4a / flac / ogg / aac |
| 大小 | ≤ 20 MB |
| 内容 | 单人连续说话，不是音乐、不是多人对话 |

用手机录一段 15 秒的说话声，导出 mp3，基本就能过。

### 8.6 提示 `model_not_supported`

你指定的模型名不在清单里。先问它「列出可用的语音模型」，
用返回列表里的名字，或者干脆**不指定模型**让它用默认的。

### 8.7 提示 `rate_limited`（太频繁）

调用太快被限流了。**等几十秒再试**即可。

### 8.8 DeepseekHarness 里看不到这四个工具

按顺序排查：

1. 先在 PowerShell 里跑 `qwen-voice-mcp selftest`，确认服务本身没问题（见 8.1）
2. 检查 5.2 里填的**命令和参数**，特别是路径要用正斜杠 `/`
3. **重启 DeepseekHarness**（改完 MCP 配置必须重启才生效）
4. 在 DeepseekHarness 的 **设置 → MCP** 里看这个服务器的状态指示灯，有没有报错信息
5. 检查 Python 路径是否写对：`qv` 那行能跑通，说明路径对；把它填进 DSH 的「命令」字段

### 8.9 生成的音频找不到

音频默认存在：

```
C:\Users\你的用户名\AppData\Roaming\qwen-voice-mcp\output\
```

把上面这条路径（把「你的用户名」换成实际的）粘到资源管理器地址栏，回车。

> ℹ️ 程序会自动清理 **24 小时前**的临时文件，所以别隔天再来找。

### 8.10 想彻底重来

```powershell
qwen-voice-mcp config clear-key
```

然后再执行一次第 4 章。如果想连配置一起重置，删掉这个文件夹：

```
C:\Users\你的用户名\AppData\Roaming\qwen-voice-mcp\
```

## 9. 花不花钱？花多少？

| 操作 | 花钱吗 |
|---|---|
| 查模型清单、查余额、自检、探测模型 | **不花钱** |
| 文字转语音 | 按**文字字数**计费 |
| 克隆音色 | 按**次**计费（相对贵一些） |

具体单价以阿里云百炼控制台的价目为准——程序里显示的预估价格只是**本地估算**，
用于余额保护判断，**不一定等于实际账单**。

几条省钱建议：

1. **先用短句子试**：「你好」比「请把这篇三千字的文章读一遍」便宜得多
2. **克隆音色前先确认录音合格**（5～60 秒），不合格会被拒绝、不产生费用，但反复试很浪费时间
3. **保留默认的余额安全线**（¥1.00），这是最好的防超支手段
4. **查余额是免费的**，随时可以问
5. 用完把生成的音频及时归档，程序 24 小时后会清理临时文件

## 10. 安全须知

### 关于你的密钥

- ✅ 密钥存在**本机加密文件**里，通过界面或命令写入即可
- ❌ **不要**把密钥贴到聊天群、论坛、截图、记事本或代码仓库
- ❌ **不要**把密钥写进 `.env` 文件后提交到 git
- ⚠️ 本项目**绝不会**把密钥写进日志或错误信息。日志里出现的永远是
  `sk-abc…6789` 这种打了点的形式

### 关于克隆别人的声音

克隆音色涉及**声音这种生物特征**。请务必：

- ✅ 只克隆**你自己**，或**已获得对方明确授权**的声音
- ❌ **不要**克隆公众人物、明星、同事、家人的声音用于任何欺骗性用途
- ⚠️ 未经授权克隆并使用他人声音，可能违反法律和平台规则

### 关于 HTTP 模式（进阶）

如果你用的是 `streamable-http` 模式（不是默认的 stdio），请：

- 保持只监听 `127.0.0.1`（默认就是这样，只有本机能连）
- 设置一个访问令牌：

```powershell
$env:QWEN_VOICE_HTTP_AUTH_TOKEN = "自己编一个又长又乱的字符串"
qwen-voice-mcp run --transport streamable-http --port 8765
```

**新手建议**：就用默认的 `stdio` 模式，不需要操心这些。
